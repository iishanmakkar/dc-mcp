Install Agentic Data Cleaner

Connect your favorite AI tools to our hosted Model Context Protocol (MCP) server to sanitize and structure your data in seconds.

Ready for Production

  • The server is hosted at dc-mcp-26zy.onrender.com
  • No API key needed — point your client at the endpoint below (key holders get the full tier)

1. Client Configuration

MCP Streamable HTTP
https://dc-mcp-26zy.onrender.com/mcp

Installation Steps:

  1. 1 Open your AI client's MCP settings and add a remote server entry.
  2. 2 Add a new plugin with name "DataCleaner".
  3. 3 Paste the JSON configuration snippet provided on the right — no API key needed.
JSON 
{
  "mcpServers": {
    "agentic-data-cleaner": {
      "url": "https://dc-mcp-26zy.onrender.com/mcp"
    }
  }
}

Troubleshooting

A 401 means the key you sent is wrong. Keyless access needs no Authorization header at all — remove it, or fix the key.

If you see a network timeout, ensure your firewall allows outbound HTTPS requests to dc-mcp-26zy.onrender.com on port 443.
