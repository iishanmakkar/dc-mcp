Frequently Asked

Is my file modified directly?
Never. The server operates on an in-memory copy of your data (the "working state"). No physical bytes are changed on your hard drive until you explicitly call the export_dataset tool to save a new version.
What types of changes need approval?
By default, the server flags any "non-deterministic" changesΓÇösuch as inferring missing categories or deleting outliersΓÇöas requiring approval. Simple formatting (uppercase to lowercase, ISO dates) can be automated in settings.
How big can my datasets be?
The self-hosted version is limited only by your local RAM. For the managed version, we support files up to 2GB per project. For larger enterprise needs, we offer custom dedicated clusters.
